# SpendLens 字体目录
#
# 开发环境 (macOS): 自动使用系统字体，无需处理。
# 云部署 (Linux): 
#   方案一：安装系统字体包
#     apt install fonts-noto-cjk
#   方案二：在此目录放置一个 .ttf 字体文件
#     推荐：Noto Sans SC Regular (思源黑体)
#     下载：https://github.com/googlefonts/noto-cjk/raw/main/Sans/OTF/SimplifiedChinese/NotoSansSC-Regular.otf
#     注意：.ttc 文件不兼容 fpdf2，请使用 .ttf 或 .otf
